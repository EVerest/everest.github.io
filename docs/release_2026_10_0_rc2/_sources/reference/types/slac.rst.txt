####
slac
####

SLAC shared types

.. _slac-State:

| **State**: *string* 
|  SLAC state enum. UNMATCHED: no matching process is running, also while the EVSE is armed by enter_bcd and waits for a CM_SLAC_PARM.REQ. MATCHING: a matching process is running, the first CM_SLAC_PARM.REQ was received; it is kept while the EV retries after a failed attempt. MATCHED: the data link is established.
|  enum:
|    - UNMATCHED
|    - MATCHING
|    - MATCHED
