#########################
charger\_information\_API
#########################

.. container:: everest-api overview

   .. raw:: html

      <div class="facts">
      <span class="chip"><span class="s-label">version</span> 1.0.0</span><span class="chip"><span class="s-label">AsyncAPI</span> 3.0.0</span>

   .. container:: lead

      EVerest API definition for the charger information module

   API for EVerest API clients providing the charger information (vendor, model, serial numbers, firmware version, ...) to EVerest. EVerest requests the information on demand; the client answers each request with a ChargerInformation object. Modules such as OCPP and the API modules request the charger information once during their startup and block until the reply arrives. If no reply arrives within cfg\_request\_reply\_to\_s seconds, EVerest continues with empty vendor and model strings, so the client should be connected and answering before EVerest starts.
