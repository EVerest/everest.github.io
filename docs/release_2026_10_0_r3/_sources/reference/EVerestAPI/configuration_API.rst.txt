.. _everest_api_configuration_API:

##################
configuration\_API
##################

.. warning::

   **Experimental API** since \2026.10.0.
   This API is exempt from the EVerest stability guarantees and the deprecation
   period. Its channels, operations and message payloads may change or be
   removed in any release without notice until it is promoted to stable. See
   the :ref:`policy on experimental components <project-experimental-components>`
   and the :ref:`experimental feature index <project-experimental-index>`.

.. container:: everest-api overview

   .. raw:: html

      <div class="facts">
      <span class="badge experimental" title="Exempt from the stability guarantees">experimental</span><span class="chip"><span class="s-label">version</span> 1.0.0</span><span class="chip"><span class="s-label">AsyncAPI</span> 3.0.0</span>
      <span class="chip"><span class="s-label">content type</span> application/json</span><span class="chip"><span class="s-label">license</span> <a href="https://opensource.org/licenses/Apache-2.0">Apache-2.0</a></span><span class="chip tag">EVerest</span><span class="chip tag">ConfigService</span></div>

   .. container:: lead

      EVerest API definition for the Config Service

   API for EVerest modules and clients to interact with the Config Service. Provides configuration slot management, module control requests, and publication of active slot and configuration update events. **Experimental.** This API is exempt from the EVerest stability guarantees and the deprecation period; channels, operations and message payloads may change without further notice until it is promoted to stable.
