Module Configuration
====================
| **connector_id**: *integer* <required>
|  Connector id of the evse manager to which this simulator is connected to
| **reset_powermeter_on_session_start**: *boolean* <optional>
| *default: True*
|  Reset absolute powermeter readings to zero when CP changes from state A to B
| **dummy_meter_value_send_on_transaction_start**: *boolean* <optional>
| *default: True*
|  Send dummy meter start value blob on transaction start
| **dummy_meter_value_blob_start**: *string* <optional>
| *default: "test start value"*
|  Dummy meter value blob sent on transaction start to be used for testing
| **dummy_meter_value_blob_stop**: *string* <optional>
| *default: "test stop value"*
|  Dummy meter value blob sent on transaction stop to be used for testing
| **ac_nominal_voltage**: *number* <optional>
| *default: 230.0*
|  Nominal AC voltage between phase and neutral in Volt, reported per phase by the simulated power meter
| **ac_nominal_frequency**: *number* <optional>
| *default: 50.0*
|  Nominal AC grid frequency in Hertz, reported per phase by the simulated power meter
| **ac_line_impedance_ohm**: *number* <optional>
| *default: 0.5*
|  Line impedance in Ohm per phase between the grid and the simulated power meter. The reported phase voltage drops by ac_line_impedance_ohm * current, so the reported power is below ac_nominal_voltage * current while charging. Set to 0 to always report the nominal voltage.
| **measurement_noise_percent**: *number* <optional>
| *default: 1.0*
|  Peak amplitude in percent of the uniformly distributed random noise applied to the simulated voltages, currents, CP voltage, PP resistor and RCD current. Set to 0 for deterministic readings. The CP voltage is decoded with a +-1.1 V window, so values above a few percent break the CP state detection.
| **frequency_noise_percent**: *number* <optional>
| *default: 0.25*
|  Peak amplitude in percent of the uniformly distributed random noise applied to the simulated grid frequency. Set to 0 for a deterministic frequency reading.
| **max_current_A_import**: *number* <optional>
| *default: 32.0*
|  Maximum import current in amps reported as a hardware capability. The default matches a 32 A AC wallbox. DC configurations must raise this, since the energy manager derives the available power from max_current_A_import * max_phase_count_import * nominal_voltage_V and would otherwise cap a high-power DC supply at the AC-side figure.
| **min_current_A_import**: *number* <optional>
| *default: 6.0*
|  Minimum import current in amps reported as a hardware capability
| **caps_min_current_A**: *integer* <optional>
| *default: -1*
|  Minimal current on AC side reported in hardware capabilities. -1 means use min_current_A_import for import and the built-in default for export (0 A).
| **caps_max_current_A**: *integer* <optional>
| *default: -1*
|  Maximum current on AC side reported in hardware capabilities. -1 means use max_current_A_import for import and the built-in default for export (16 A).
