Module Configuration
====================
| **cfg_communication_check_to_s**: *integer* <optional>
| *default: 5*
|  Maximum time between two communication check events. Values <= 0 disables communication checks.
| **cfg_heartbeat_interval_ms**: *integer* <optional>
| *default: 1000*
|  Interval between two heartbeat messages send by the API. Values <= 0 disable heartbeat.
| **cfg_request_reply_to_s**: *integer* <optional>
| *default: 10*
|  Maximum time between a set_value request and its reply. After timeout the write is answered Rejected. The variables of one SetVariables.req are written one after the other, so the number of variables in a request times this timeout has to stay below the message timeout of the CSMS. The maximum stays below the time after which EVerest aborts a command.
| **cfg_expected_owners**: *string* <optional>
| *default: ""*
|  Comma separated list of the owners whose registrations the module waits for before it answers get_registrations. Whitespace around a name is ignored. A registration without owner counts as the module id. When empty, the module collects registrations for cfg_registration_timeout_s instead.
| **cfg_expected_owners_timeout_s**: *integer* <optional>
| *default: 60*
|  Maximum time to wait for the expected owners after get_registrations was called. At the deadline, the module answers with the registrations it has and logs the owners still missing. The maximum stays below the time after which EVerest aborts a command.
| **cfg_registration_timeout_s**: *integer* <optional>
| *default: 10*
|  Time to collect registrations after get_registrations was called, when cfg_expected_owners is empty. The maximum stays below the time after which EVerest aborts a command.
