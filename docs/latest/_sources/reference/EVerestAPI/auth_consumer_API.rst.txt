###################
auth\_consumer\_API
###################

.. container:: everest-api overview

   .. raw:: html

      <div class="facts">
      <span class="chip"><span class="s-label">version</span> 1.1.0</span><span class="chip"><span class="s-label">AsyncAPI</span> 3.0.0</span>

      EVerest API definition for auth consumer

   API for EVerest API clients that consume authorization events from an Auth module. Provides token validation status updates and the ability to withdraw previously granted authorizations.

send\_request\_withdraw\_authorization
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. container:: everest-api op send

   .. raw:: html

      <div class="op-head">
      <span class="badge send" title="Published by the client, consumed by EVerest">send</span>

      <span class="op-title">Withdraw granted authorization.</span></div>
      <dl class="op-facts">
      <dt>Topic</dt>
      <dd><code class="topic" data-copy="everest_api/1/auth_consumer/{module_id}/m2e/withdraw_authorization">everest_api/1/auth_consumer/{module_id}/m2e/withdraw_authorization</code></dd>
      <dt>Reply</dt>
      <dd>Sent to <code>$message.header#/replyTo</code> as <a href="#everest-api-auth-consumer-api-op-receive-reply-withdraw-authorization">receive_reply_withdraw_authorization</a>.</dd>
      </dl>

   If only the evse\_id is given, the granted authorization for this EVSE will be withdrawn. If only the id\_token is given, the granted authorization for every EVSE where this id\_token is placed will be withdrawn. If both parameters are given, the granted authorization for the given EVSE will be withdrawn, if the placed id\_token matches the given id\_token If no parameter is given, all granted authorizations for all EVSEs will be removed
