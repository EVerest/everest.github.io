configuration_API¶

Warning

Experimental API since 2026.10.0. This API is exempt from the EVerest stability guarantees and the deprecation period. Its channels, operations and message payloads may change or be removed in any release without notice until it is promoted to stable. See the policy on experimental components and the experimental feature index.

experimentalversion 1.0.0AsyncAPI 3.0.0 content type application/jsonlicense Apache-2.0EVerestConfigService

EVerest API definition for the Config Service

API for EVerest modules and clients to interact with the Config Service. Provides configuration slot management, module control requests, and publication of active slot and configuration update events. Experimental. This API is exempt from the EVerest stability guarantees and the deprecation period; channels, operations and message payloads may change without further notice until it is promoted to stable.

Specification: configuration_API.yaml · pionix:de:everest:configuration_API

send the client publishes, EVerest consumes (10) receive EVerest publishes, the client consumes (12)

ConfigurationParameterUpdateResultEnum string¶
string

Result for a configuration parameter update request for a single parameter.

  • Applied: Update was accepted and applied successfully. The change is effective immediately.
  • WillApplyOnRestart: Update was accepted and applied successfully. The change will become effective on the next start of the slot (which may be immediately if modules are being restarted, or on the next restart if modules are currently running).
  • RetryLater: Update was rejected, because it couldn't be processed now, but it might succeed at a later time
  • DoesNotExist: Rejected, because the specified configuration parameter does not exist
  • AccessDenied: Rejected, because the access was denied
  • Rejected: Rejected for other reasons (e.g. invalid value format, invalid value for enum, etc.)
enumAppliedWillApplyOnRestartRetryLaterDoesNotExistAccessDeniedRejected
