generic\_error\_raiser\_API
###########################

.. container:: everest-api overview

   .. raw:: html

      <div class="facts">
      <span class="chip"><span class="s-label">version</span> 1.1.0</span><span class="chip"><span class="s-label">AsyncAPI</span> 3.0.0</span>
      <span class="chip"><span class="s-label">content type</span> application/json</span><span class="chip"><span class="s-label">license</span> <a href="https://opensource.org/licenses/Apache-2.0">Apache-2.0</a></span><span class="chip tag">EVerest</span><span class="chip tag">generic errors</span></div>

   .. container:: lead

      EVerest API definition for raising and clearing generic errors

   API for EVerest API clients for raising and clearing generic errors. The errors are only reported, e.g. by OCPP and the error history. EvseManager does not act on them, so they do not stop charging.
