Module Configuration
====================
| **device**: *string* <optional>
| *default: "auto"*
|  Ethernet device used for HLC. auto picks the first interface with an IPv6 link-local address at startup and fails the module start when there is none.
| **evcc_id**: *string* <optional>
| *default: "02:00:00:00:00:01"*
|  EVCC identifier sent to the SECC in ISO 15118-20 SessionSetup, 1 to 255 characters. Both forms are valid, a MAC address (02:00:00:00:00:01) and a vehicle identifier (WMIV1234567890ABCDEX). ISO 15118-2 and DIN SPEC 70121 do not use it; their EVCCID is the 6 byte MAC of `device`.
| **response_timeout_ms**: *integer* <optional>
| *default: 0*
|  Response watchdog timeout in milliseconds. 0 uses the per-message ISO 15118 timeouts from the specification table.
| **authorization_timeout_ms**: *integer* <optional>
| *default: 0*
|  Bound on the ISO 15118-20 authorization loop, in milliseconds. The EV re-sends AuthorizationReq while the EVSE reports Ongoing and after a declined attempt, so the driver can authorize again, and stops the session once this bound expires. 0 uses V2G_EVCC_Ongoing_Timeout (60000 ms) from the specification table.
| **control_mode**: *string* <optional>
| *default: "Dynamic"*
|  Preferred charge-loop control mode, ISO 15118-20 only; ISO 15118-2 and DIN SPEC 70121 always run scheduled. The EV selects the SECC parameter set matching this preference and falls back to the first offered set when the preference is not offered.
|  enum:
|    - Scheduled
|    - Dynamic
| **supported_protocols**: *string* <optional>
| *default: ""*
|  Comma-separated protocols the EV offers in the SAP handshake, highest priority first, from ISO15118_20, ISO15118_2 (AC and DC, EIM or Plug&Charge, TLS 1.2 or plaintext) and DIN70121 (DC, plaintext only), e.g. "ISO15118_20,ISO15118_2". Empty unless set, so a configuration offers only the protocols it lists. The module fails at startup when the list is empty, names an unknown protocol, or names one twice.
| **tls**: *string* <optional>
| *default: "off"*
|  Transport security. off runs plaintext only and requests no TLS in SDP; ISO 15118-20 over plaintext deviates from [V2G20-2677] and is meant for testing, and Plug&Charge over it also needs allow_pnc_without_tls. prefer requests TLS in SDP and accepts a plaintext offer. require rejects an SDP response without TLS.
|  enum:
|    - off
|    - prefer
|    - require
| **allow_pnc_without_tls**: *boolean* <optional>
| *default: False*
|  Accept the deviation from the standard and present a contract over a session with no transport security. Off, the vehicle charges by EIM on a plaintext link instead, which is the correction this repository's own charger already makes from the other end. On, the contract chain and the eMAID go out in clear in PaymentDetailsReq and a contract-key signature over a charger-chosen challenge goes out in clear in AuthorizationReq; legitimate for the [V2G2-465] robustness test and for bring-up against a plaintext test charger.
| **tls_version**: *string* <optional>
| *default: "auto"*
|  TLS version, ignored when tls is off. auto offers TLS 1.3 when ISO 15118-20 is in the offer and the vehicle chain is usable, and TLS 1.2 when ISO 15118-2 is; after the handshake it offers only ISO 15118-20 over 1.3 and only ISO 15118-2 over 1.2. With no version left start_charging is rejected, or the session stops at connect when the chain files turn out unusable. "1.2" and "1.3" pin exactly that version and offer every enabled protocol over it, with a startup warning for ISO 15118-2 over 1.3 or ISO 15118-20 over 1.2. TLS 1.3 presents the vehicle certificate (ISO 15118-20); TLS 1.2 presents none (ISO 15118-2).
|  enum:
|    - auto
|    - 1.2
|    - 1.3
| **verify_server_certificate**: *boolean* <optional>
| *default: True*
|  Verify the SECC certificate chain against the V2G root.
| **enable_tls_key_logging**: *boolean* <optional>
| *default: False*
|  Export the TLS session keys (pre-master-secret) of the handshake. For testing and simulation only.
| **tls_key_logging_path**: *string* <optional>
| *default: "/tmp"*
|  Output directory for the TLS key log file. With enable_tls_key_logging, empty is a configuration error, logged when TLS is set up; key logging then stays off.
| **pki_path**: *string* <optional>
| *default: ""*
|  Directory holding the EV certificates and keys. Each certificate and key path below that is left empty resolves under it, written <pki_path> there. Empty selects <etc>/certs, the certs directory of the EVerest etc path.
| **v2g_root_cert_path**: *string* <optional>
| *default: ""*
|  Path to the V2G root certificate. Empty resolves to <pki_path>/ca/v2g/V2G_ROOT_CA.pem. Every certificate in the file is trusted, so under tls_version auto it must hold both the ISO 15118-2 and the ISO 15118-20 V2G roots.
| **device_cert_chain_path**: *string* <optional>
| *default: ""*
|  Path to the vehicle (TLS client) certificate chain, leaf first. Empty resolves to <pki_path>/client/vehicle/VEHICLE_CERT_CHAIN.pem.
| **device_key_path**: *string* <optional>
| *default: ""*
|  Path to the vehicle leaf private key. Empty resolves to <pki_path>/client/vehicle/VEHICLE_LEAF.key.
| **device_key_password_path**: *string* <optional>
| *default: ""*
|  Path to the file holding the password of the vehicle leaf private key. Empty resolves to <pki_path>/client/vehicle/VEHICLE_LEAF_PASSWORD.txt; a missing or empty file means no password.
| **iso2_ac_e_amount_wh**: *number* <optional>
| *default: 60000*
|  ISO 15118-2 AC_EVChargeParameter EAmount, the energy the EV asks for, in watt-hours. The -20 AC parameters below are power based and do not carry this value.
| **iso2_ac_ev_max_voltage_v**: *number* <optional>
| *default: 400*
|  ISO 15118-2 AC_EVChargeParameter EVMaxVoltage in volts (per line).
| **iso2_ac_ev_max_current_a**: *number* <optional>
| *default: 32*
|  ISO 15118-2 AC_EVChargeParameter EVMaxCurrent in amperes (per line).
| **iso2_ac_ev_min_current_a**: *number* <optional>
| *default: 10*
|  ISO 15118-2 AC_EVChargeParameter EVMinCurrent in amperes (per line).
| **enable_pnc**: *boolean* <optional>
| *default: False*
|  Offer ISO 15118-2 Plug&Charge (Contract) next to EIM and select Contract whenever the SECC offers it. Requires TLS; without it the EV falls back to EIM only. This is config driven because EvManager's default payment option is `auto`; an explicit ExternalPayment in start_charging turns the preference off for that session, and an explicit Contract keeps it on. The contract certificate material below is used for PaymentDetails and, when it is missing or pnc_force_cert_install is set, for a CertificateInstallation.
| **pnc_contract_cert_chain_path**: *string* <optional>
| *default: ""*
|  Path to one PEM file holding the whole PnC contract (MO) certificate chain, leaf first. Empty resolves to <pki_path>/client/mo/MO_LEAF.pem followed by <pki_path>/ca/mo/INTERMEDIATE_MO_CA_CERTS.pem.
| **pnc_contract_key_path**: *string* <optional>
| *default: ""*
|  Path to the PnC contract (MO) leaf private key (PEM); signs the PnC AuthorizationReq. Empty resolves to <pki_path>/client/mo/MO_LEAF.key.
| **pnc_contract_key_password_path**: *string* <optional>
| *default: ""*
|  Path to the file holding the password of the contract leaf private key. Empty resolves to <pki_path>/client/mo/MO_LEAF_PASSWORD.txt; a missing or empty file means no password.
| **pnc_oem_prov_cert_path**: *string* <optional>
| *default: ""*
|  Path to the OEM provisioning certificate (PEM). Signs CertificateInstallationReq and holds the static ECDH key that decrypts the delivered contract key. Empty resolves to <pki_path>/client/oem/OEM_LEAF.pem.
| **pnc_oem_prov_key_path**: *string* <optional>
| *default: ""*
|  Path to the OEM provisioning private key (PEM). Empty resolves to <pki_path>/client/oem/OEM_LEAF.key.
| **pnc_oem_prov_key_password_path**: *string* <optional>
| *default: ""*
|  Path to the file holding the password of the OEM provisioning private key. Empty resolves to <pki_path>/client/oem/OEM_LEAF_PASSWORD.txt.
| **pnc_force_cert_install**: *boolean* <optional>
| *default: False*
|  Run a CertificateInstallation even when a contract certificate is configured. Requires the SECC to offer the Certificate service.
| **pnc_contract_store_dir**: *string* <optional>
| *default: ""*
|  Directory that keeps the contract a CertificateInstallation delivered, as CONTRACT_CHAIN.pem (leaf first), CONTRACT_LEAF.key (mode 0600) and EMAID.txt. Every later session presents the stored contract when all three files are present and the key belongs to the leaf, and falls back to the configured contract material otherwise. Empty disables persistence. Give each Ev15118 instance its own directory; two instances sharing one can mix their files.
| **ac_phase_count**: *integer* <optional>
| *default: 3*
|  Number of AC lines the EV draws on, 1 or 3. Selects which connector the EV asks for. On a single-phase connector it divides the advertised totals below down to one line's share. A start_charging with AC_single_phase_core and 3 here runs that session on one line, with a third of the charge power totals.
|  enum:
|    - 1
|    - 3
| **ac_max_charge_power_w**: *number* <optional>
| *default: 11040*
|  Advertised AC maximum charge power in watts, as a total across ac_phase_count lines. The default is 16 A x 230 V x 3.
| **ac_min_charge_power_w**: *number* <optional>
| *default: 4140*
|  Advertised AC minimum charge power in watts, as a total across ac_phase_count lines. The default is 6 A x 230 V x 3.

| **der_volt_var_mode**: *boolean* <optional>

| **der_watt_var_mode**: *boolean* <optional>
| *default: False*
|  Declare support for the IEC WattVarMode DER control function.
| **der_watt_cos_phi_mode**: *boolean* <optional>
| *default: False*
|  Declare support for the IEC WattCosPhiMode DER control function.
| **der_dso_q_setpoint_provision**: *boolean* <optional>

| **der_dc_injection_restriction**: *boolean* <optional>

|  Declare support for the IEC DCInjectionRestriction DER control function.
